========================================================
 《透明的她与真实的我》 朗读模组  v1.7
========================================================

一句话说明
--------------------------------------------------------
让读屏软件朗读游戏里没有配音的文字：剧情旁白、主角「我」的
台词、手机（WeSay）聊天消息。有配音的台词不朗读，只放语音。

语音后端自动按可用性挑选：
  1. Tolk        装了就用（支持 NVDA / JAWS / SuperNova / ZoomText）
  2. NVDA        没装 Tolk 但有 NVDA 就用这个
  3. SAPI        Windows 内置语音，不装任何读屏也能出声
启动后看日志里的「语音后端: xxx」就知道用了哪个。


朗读什么 / 不朗读什么
--------------------------------------------------------
[会朗读]
  · 无配音的剧情文本（旁白、主角「我」、少量无配音配角）
  · 手机（WeSay）聊天消息
  · 手机聊天里的表情/图片 → 提示为「图片」
  · 选项内容（剧情选项 + 手机选项）

[不会朗读]
  · 有配音的台词 —— 只播放语音，并且会打断上一句未读完的朗读，
    避免朗读和配音重叠


按键
--------------------------------------------------------
  数字键 1 - 9      选择对应编号的选项（剧情选项、手机选项通用）
                    —— 这是必须的，因为游戏原本的选项按钮是按屏幕
                       坐标散落摆放的，读屏无法定位
                    （已核对全部剧本：选项批次最多 4 个，1-9 够用）

  Backspace         重读当前这一句          ← v1.1 改的，原本是 R

  空格 / 回车       推进对话（游戏原有）
  Ctrl              快进（游戏原有，快进时不朗读）

【重要】以下按键游戏原生占用，模组不会去抢，你也不要拿它们当重读键：
  A      自动模式
  F      快进
  P      打开主菜单
  R      打开历史回顾（Ending2 里是语音收藏）  ← v1.0 曾与此冲突
  Esc    菜单 / 返回
  Ctrl   快进
  空格 / 回车 / 小键盘回车   推进

  重读键可以在配置里改成任意 KeyCode 名称，例如 Tab、Q、Home、F1。
  留空则关闭重读功能。

菜单 / 存档 / 设置 / 画廊（v1.4 新增）
--------------------------------------------------------
游戏原本这些界面几乎只能鼠标点，现在可以纯键盘操作并朗读：

  Tab          进入 / 退出导航模式（进入时朗读「共 N 项」）
  上 / 下      上一项 / 下一项（会朗读项目名称、类型、状态）
  左 / 右      调整滑条（每按一次朗读新数值）
  回车 / 空格  激活 —— 按钮则点击，开关则切换，输入框则进入输入
  Home / End   跳到第一项 / 最后一项
  PageUp/PageDown  切换面板组

  朗读内容示例：
    「设置，按钮，3 / 12」
    「全屏显示，开关，开，7 / 12」
    「音乐音量，滑条，75 / 100，8 / 12」
    「姓氏，输入框，当前内容 李，9 / 12」

  进入输入框后会自动退出导航模式，直接把键盘交给输入；
  按 Tab 可随时回到导航模式。

  激活按钮或开关后会自动重新扫描界面（下一帧），
  弹出的确认框会直接接上，不需要再按一次 Tab。

  ★ 只导航最上层面板（v1.7 起）
    实测存档界面一次能扫到 13~20 个控件，其中只有 5 个是存档槽，
    其余是设置页签、画廊等无关按钮。现在按「Canvas 下的顶层面板」
    分组，默认只进入最上层那一组，避免在噪声里找目标。
    需要访问其它面板时按 PageUp / PageDown 切换。

  ★ 槽位标签会拼接多个字段（v1.7 起）
    存档槽有「名字 / 时间 / 章节」三个文本，之前只读第一个，
    导致 5 个空槽都读成「无存档」，听起来像只能选一个。
    现在会把不同的文本拼起来读，例如「无存档，--/--/--，空存档」。

  ★ 排序与视觉反馈
    排序按「渲染层级 → 屏幕位置」，最上层面板排最前，
    因此确认框一弹出，按 Tab 后听到的头两项就是它。
    导航时会同步设置 EventSystem 选中项，游戏自身的按钮高亮
    会跟着走，看得见的操作者也能看到焦点在哪。


安装
--------------------------------------------------------
本模组已经装好了。如需重新安装：

  在 PowerShell 里进入本文件夹，执行：
      .\安装.ps1

如果游戏不在默认位置：
      .\安装.ps1 -GameDir "X:\你的路径\Transparenther"

安装程序只新增文件，绝不覆盖游戏原有文件；一旦发现冲突会
直接中止并列出清单。


卸载
--------------------------------------------------------
  .\卸载.ps1

或者手动删掉游戏目录下这几项（都是本模组新增的）：
      winhttp.dll
      doorstop_config.ini
      .doorstop_version
      changelog.txt
      BepInEx\            （整个文件夹）
      nvdaControllerClient.dll

删掉 winhttp.dll 就足以让模组完全失效，游戏恢复原样。


使用前提
--------------------------------------------------------
  1. NVDA 必须在游戏启动前就已经在运行
  2. 必须从 Steam 正常启动游戏（不要直接双击 exe）


配置
--------------------------------------------------------
首次启动游戏后，会生成配置文件：

  <游戏目录>\BepInEx\config\transparenther.a11y.reader.cfg

用记事本打开，把 true 改成 false 即可关闭对应功能。
改完保存，重启游戏生效。

配置项：

  [朗读]
  朗读无配音剧情 = true
      关掉就完全不朗读剧情文本

  无法判定时也朗读 = true
      万一模组认不出当前这行有没有配音，选择朗读而不是跳过。
      建议保持 true，宁可多读也不要漏读。

  朗读时带上说话人 = true
      朗读时前面加上「诗萌：」「何璐：」这样的名字。
      旁白没有名字，不会加。

  朗读手机消息 = true
      手机（WeSay）聊天

  朗读手机表情 = true
      手机聊天里的表情/图片提示为「图片」

  朗读选项 = true
      出现选项时朗读全部选项

  数字键选择选项 = true
      用 1-9 选择选项。关掉之后就只能用鼠标点。

  限时选择不自动选 = true
      ★ 重要。游戏共 246 处「实时」限时选择，原本 8 秒后
      会由系统自动替你选默认项 —— 朗读还没念完选项就被代选了。
      开启后不再自动选，一直等你按数字键。
      关掉即恢复游戏原本的 8 秒倒计时。

  重读按键 = Backspace
      重读当前句的按键。填 KeyCode 名称，留空关闭。
      不要填 R / P / A / F / Ctrl / 空格 / 回车（游戏占用）。


出问题了怎么办
--------------------------------------------------------
1) 完全没有声音
   · 打开 <游戏目录>\BepInEx\LogOutput.log，找这一行：
        语音后端: xxx
     - "Tolk (...)"  → 走 Tolk
     - "NVDA"        → 走 NVDA
     - "SAPI"        → 没检测到读屏，用的系统语音
     - "无"          → 三个后端都不可用，日志下方会有原因
   · 若显示 SAPI 但你想要 NVDA：确认 NVDA 在游戏启动前就开着

2) 游戏打不开 / 黑屏
   · 删掉 <游戏目录>\winhttp.dll，游戏立刻恢复原样
   · 或者打开 doorstop_config.ini，把 enabled = true 改成 false

3) 朗读和配音同时响
   · 说明某行的配音识别失败了。把「无法判定时也朗读」关掉试试，
     但可能会漏读一些行。也欢迎反馈是哪一段。

4) 有文字没被朗读
   · 看 LogOutput.log 里有没有相关记录
   · 可能是那种台词不在模组识别的两条代码路径上


技术说明（给愿意看的人）
--------------------------------------------------------
· 加载器：BepInEx 5.4.23.5（Unity Mono 版，winhttp.dll 代理注入）
· 朗读通道：NVDA Controller Client（官方 x64 构建），
  许可证 LGPL-2.1，允许随程序分发
· 工作方式：Harmony 运行时补丁，不修改任何游戏文件
· 挂载点：
    DialogueSceneManager.StartTyping       → 剧情文本（普通流程）
    Ending2DialogueManager.StartTyping     → 剧情文本（结局流程）
    PhoneDialogueManager.AddMessage        → 手机消息
    PhoneDialogueManager.HandleExpressionMessage → 手机表情
    DialogueSceneManager.GenerateReplyButton /
    GenerateSelectionButton                → 剧情选项
    PhoneDialogueManager.HandleChoiceMessages → 手机选项
· 判定是否有配音：用传入的最终文本反查 DialogueScene，
  读它的 VoiceFilename 字段是否为空
· 所有文件均在 <游戏目录> 内，不写注册表，不动系统目录
