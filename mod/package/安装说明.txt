========================================================
 《透明的她与真实的我》 NVDA 朗读模组  v1.0
========================================================

一句话说明
--------------------------------------------------------
让 NVDA 朗读游戏里没有配音的文字：剧情旁白、主角「我」的
台词、手机（WeSay）聊天消息。有配音的台词不朗读，只放语音。


朗读什么 / 不朗读什么
--------------------------------------------------------
[会朗读]
  · 无配音的剧情文本（旁白、主角「我」、少量无配音配角）
  · 手机（WeSay）聊天消息
  · 手机聊天里的表情/图片 → 提示为「图片」
  · 选项内容（剧情选项 + 手机选项）

[不会朗读]
  · 有配音的台词 —— 只播放语音，并且会打断上一句未读完的朗读，
    避免朗读和配音重叠


按键
--------------------------------------------------------
  数字键 1 - 9      选择对应编号的选项（剧情选项、手机选项通用）
                    —— 这是必须的，因为游戏原本的选项按钮是按屏幕
                       坐标散落摆放的，读屏无法定位
                    （已核对全部剧本：选项批次最多 4 个，1-9 够用）

  Backspace         重读当前这一句          ← v1.1 改的，原本是 R

  空格 / 回车       推进对话（游戏原有）
  Ctrl              快进（游戏原有，快进时不朗读）

【重要】以下按键游戏原生占用，模组不会去抢，你也不要拿它们当重读键：
  A      自动模式
  F      快进
  P      打开主菜单
  R      打开历史回顾（Ending2 里是语音收藏）  ← v1.0 曾与此冲突
  Esc    菜单 / 返回
  Ctrl   快进
  空格 / 回车 / 小键盘回车   推进

  重读键可以在配置里改成任意 KeyCode 名称，例如 Tab、Q、Home、F1。
  留空则关闭重读功能。


安装
--------------------------------------------------------
本模组已经装好了。如需重新安装：

  在 PowerShell 里进入本文件夹，执行：
      .\安装.ps1

如果游戏不在默认位置：
      .\安装.ps1 -GameDir "X:\你的路径\Transparenther"

安装程序只新增文件，绝不覆盖游戏原有文件；一旦发现冲突会
直接中止并列出清单。


卸载
--------------------------------------------------------
  .\卸载.ps1

或者手动删掉游戏目录下这几项（都是本模组新增的）：
      winhttp.dll
      doorstop_config.ini
      .doorstop_version
      changelog.txt
      BepInEx\            （整个文件夹）
      nvdaControllerClient.dll

删掉 winhttp.dll 就足以让模组完全失效，游戏恢复原样。


使用前提
--------------------------------------------------------
  1. NVDA 必须在游戏启动前就已经在运行
  2. 必须从 Steam 正常启动游戏（不要直接双击 exe）


配置
--------------------------------------------------------
首次启动游戏后，会生成配置文件：

  <游戏目录>\BepInEx\config\transparenther.a11y.reader.cfg

用记事本打开，把 true 改成 false 即可关闭对应功能。
改完保存，重启游戏生效。

配置项：

  [朗读]
  朗读无配音剧情 = true
      关掉就完全不朗读剧情文本

  无法判定时也朗读 = true
      万一模组认不出当前这行有没有配音，选择朗读而不是跳过。
      建议保持 true，宁可多读也不要漏读。

  朗读时带上说话人 = true
      朗读时前面加上「诗萌：」「何璐：」这样的名字。
      旁白没有名字，不会加。

  朗读手机消息 = true
      手机（WeSay）聊天

  朗读手机表情 = true
      手机聊天里的表情/图片提示为「图片」

  朗读选项 = true
      出现选项时朗读全部选项

  数字键选择选项 = true
      用 1-9 选择选项。关掉之后就只能用鼠标点。

  重读按键 = Backspace
      重读当前句的按键。填 KeyCode 名称，留空关闭。
      不要填 R / P / A / F / Ctrl / 空格 / 回车（游戏占用）。


出问题了怎么办
--------------------------------------------------------
1) 完全没有声音
   · 确认 NVDA 在游戏启动前就开着了
   · 打开 <游戏目录>\BepInEx\LogOutput.log，搜索 "NVDA"
     - "DLL 未加载"  → nvdaControllerClient.dll 没放对位置
     - "NVDA 未运行" → NVDA 没开，或中途退了

2) 游戏打不开 / 黑屏
   · 删掉 <游戏目录>\winhttp.dll，游戏立刻恢复原样
   · 或者打开 doorstop_config.ini，把 enabled = true 改成 false

3) 朗读和配音同时响
   · 说明某行的配音识别失败了。把「无法判定时也朗读」关掉试试，
     但可能会漏读一些行。也欢迎反馈是哪一段。

4) 有文字没被朗读
   · 看 LogOutput.log 里有没有相关记录
   · 可能是那种台词不在模组识别的两条代码路径上


技术说明（给愿意看的人）
--------------------------------------------------------
· 加载器：BepInEx 5.4.23.5（Unity Mono 版，winhttp.dll 代理注入）
· 朗读通道：NVDA Controller Client（官方 x64 构建），
  许可证 LGPL-2.1，允许随程序分发
· 工作方式：Harmony 运行时补丁，不修改任何游戏文件
· 挂载点：
    DialogueSceneManager.StartTyping       → 剧情文本（普通流程）
    Ending2DialogueManager.StartTyping     → 剧情文本（结局流程）
    PhoneDialogueManager.AddMessage        → 手机消息
    PhoneDialogueManager.HandleExpressionMessage → 手机表情
    DialogueSceneManager.GenerateReplyButton /
    GenerateSelectionButton                → 剧情选项
    PhoneDialogueManager.HandleChoiceMessages → 手机选项
· 判定是否有配音：用传入的最终文本反查 DialogueScene，
  读它的 VoiceFilename 字段是否为空
· 所有文件均在 <游戏目录> 内，不写注册表，不动系统目录


重要提醒
--------------------------------------------------------
本模组**未经实机测试**（无法在打包环境里启动游戏验证）。
