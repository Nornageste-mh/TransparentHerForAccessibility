一句话说明
--------------------------------------------------------
让读屏软件朗读游戏里没有配音的文字：剧情旁白、主角「我」的
台词、手机（WeSay）聊天消息。有配音的台词不朗读，只放语音
（想听文字按 Backspace，TTS 会把这一句念一遍）。

语音后端自动按可用性挑选：
  1. Tolk        装了就用（支持 NVDA / JAWS / SuperNova / ZoomText）
  2. NVDA        没装 Tolk 但有 NVDA 就用这个
  3. 争渡读屏     只装争渡（ZDSR）就用这个 —— 走争渡自己的语音
  4. SAPI        Windows 内置语音，不装任何读屏也能出声
启动后看日志里的「语音后端: xxx」就知道用了哪个。
装了多个也没关系：按 F9 可以随时切到下一个当前可用的后端（见下面【按键】）。

【版本号怎么看】发布名是 v0.5.10.3，BepInEx 日志与配置文件里显示成 0.5.10.3，
  是同一个版本。
  版本号字段必须能解析成版本号：带字母的写法（比如 0.5.8a）会被判定
  "version is invalid" 并**静默跳过整个插件** —— 表现是模组完全没加载、
  游戏里一片安静，极难排查。要表达「第五版修订」请用第四位数字，如 0.5.8.1。
配置「语音后端」填成 Tolk / NVDA / 争渡 / SAPI 可以把它钉死在某一个上，
排查「到底是哪个后端不响」时很有用（钉死之后不会自动降级）。

【v0.5.10.3 新增】**折跃界面能左右滚动了，屏幕外的章节也能选中**。上一版解决了
  「念编号」，但折跃那张节点图比屏幕宽三倍多（内容 12238 宽，视口只有 3840），
  用 Tab 往右走，走到可见区边缘就停住 —— 大半章节根本选不到，画面也不动。
  · 现在整张图里的节点都能走到：焦点落到屏幕外的节点时，画面会自动滚过去
    （能整个放下就居中，放不下贴到最近边），横向滚动位置跟着焦点走。
  · 左右键在折跃这类「横向列表」里改成上一项 / 下一项（画面同步滚动）；
    在设置界面的滑条上仍然是调值，两者不会打架。
  · 未解锁的章节（游戏把它们设成完全透明）**不会**被补进清单 —— 免得把还没
    解锁的章节标题念出来剧透。
  · 顺带：其它纵向滚动的面板（BGM 列表、CG 一览等）焦点走到屏外项时也会滚过去。
  · 关于「节点要不要念第 X 周目」：查过了，游戏数据里**没有**「每个节点属于第几
    周目」这个字段（只有全局的当前周目数），场景里也没有周目标签文本。硬编对照表
    会随游戏更新失效、还会把剧情结构写进源码，所以这版不做，如实说明。

【v0.5.10.2 新增】**折跃界面朗读节点标题**。以前用 Tab 在折跃界面（跳章节那
  张节点图）里挑节点，听到的是 `JumpPrefab (12)` 这样的预制体名字 —— 既不是
  标题，那个数字也不代表第几章（它只是同名预制体的实例编号，跟解锁进度有关）。
  · 节点按钮是纯图片、没有文字组件，但标题本来就在游戏数据里
    （`NodeData.description`）。现在模组读这一格来当标签，听到的是
    「`56ys5LqU56ugICDlnKPngavllrXllrXkv53ljavmiJg=`，按钮，6 / 16」这样（这一串 Base64 解码后是那一章的标题，刻意不直接写出来防剧透）。
  · 只对折跃节点生效，其它界面一个字都不会变。万一以后游戏改了数据结构，
    这一层会自己失效、退回原来的「念对象名」，不会崩也不会更糟。
  · 同一张面板上还有「返回 / 菜单 / 横向滚动条」三个控件仍念英文对象名，
    这次没动（还没实机确认它们各自到底是什么），留到下一版。

【v0.5.10.1 新增】**自动找到争渡的安装目录**，并且包里带一份**兜底 dll**。
  上一版让争渡这一级能出声了，但前提是模组能**找到** ZDSRAPI*.dll ——
  找不到照样不可用，而官方文档那句「直接调用争渡安装目录下的相应 dll」
  默认读者知道安装目录在哪。装在别的盘、自己改过目录的人就卡在这儿。
  · 现在模组会先读 Windows「卸载」登记项里的 InstallLocation
    （DisplayName 含「争渡」或 zdsr 的那些；HKLM 两个视图 + HKCU 都枚举），
    找不到再试 %ProgramFiles(x86)%\zdsr\zdsr 这类默认位置。
    **你是装在别的盘、装到自定义目录也算数，不用告诉它。**
  · 搜索顺序：注册表登记的安装目录 → 默认安装目录 → 插件目录（包内那份）
    → 游戏目录。**安装目录里那份永远优先**（它会跟着读屏一起升级）。
  · 发布包的 BepInEx\plugins\ 里**另外带了 ZDSRAPI_x64.dll 与 ZDSRAPI.dll
    两份兜底**（32 / 64 位各一）。带它只是为了那些在自己机器上翻不到这个
    dll 的人。**删掉这两个文件即可回到「只读安装目录」**，功能不变。
    详见下面【安装】里的清单与【技术说明】。
  · 包内那份是**打包机**上的版本，可能比你本机的争渡旧；**旧了也不要紧**：
    模组发现它报「版本不匹配」（InitTTS 返回 1）时会**自动换下一份候选**，
    不会把你卡住。
  · 排查用的环境变量 A11Y_ZDSR_DIR 现在可以写多个目录、用分号分隔；
    一旦设置就只找它列出的目录（日常用不到）。

【v0.5.10.0 新增】争渡读屏（ZDSR）这一级。以前只装争渡的机器只能听到
  系统语音（SAPI）—— 音色、语速、音量都不是自己平时听的那一套。
  现在从**争渡安装目录**加载它官方的 ZDSRAPI，让争渡用户听到自己的读屏语音。
  · 判断争渡能不能用，看的是 GetSpeakState() 返回 3（正在朗读）或 4（空闲），
    **不是** Speak() 的返回值 —— 未授权时 Speak() 照样返回 0，
    拿它当判据会变成「配置选了争渡、日志一片绿、耳朵一片安静」。
  · API 权限只随争渡**商业版 / 青春版**提供；公益档下争渡会一直回答
    「没运行或未授权」，此时模组如实判它不可用，并继续往下试 SAPI。
  · 这一级接通了，等于推翻了 v0.5.8a 里那句「争渡直连走不通」——
    那句话的依据是 Speak() 的返回码，而那个判据本身是错的。
    授权限制本身仍然存在，绕不过。
  · 另新增「切换语音后端按键」（默认 F9）：运行中按一下切到下一个
    当前可用的后端，选择会写进配置文件，下次启动仍生效。

【v0.5.9.0 修复】有配音的台词，按 Backspace 重读不出声。
  重读按键原来和「0.4 秒内去重」共用同一个变量，而「有配音」这条分支
  会把它一起清成空串 —— 于是语音错过了、或者没听清，退格也翻不回来。
  现在拆成两个：去重归去重，重读缓冲区**有配音的台词也记**。
  自动朗读的行为没变（有配音仍然只放语音、仍然打断上一句），
  只是你主动按 Backspace 时，TTS 会把这一句念出来。

【v0.5.8a 修复】SAPI（系统语音）这条兜底以前**从来没出过声**。
  原因：代码走的是 COM 后期绑定，而游戏用的 Mono 没实现它，只会在日志里
  留下一句 SAPI 不可用: NotImplementedException。
  后果：没装 NVDA、也没装 Tolk 的机器（比如只装了争渡读屏的）三级后端全灭，
  整局游戏一片安静 —— 现在改成纯 P/Invoke 直接调系统语音，已实测出声。


========================================================
 安装（把文件拷进游戏目录，没有安装程序）
========================================================

补丁是运行时挂载的，不修改任何游戏文件，所以安装就是「拷文件」。

【第 1 步】找到游戏根目录
  就是有 TransparentHer.exe 的那一层。Steam 默认在：
    ...\steamapps\common\Transparenther\
  免 Steam 试玩版一般在：
    ...\steamapps\common\透明的她与真实的我 Demo\

【第 2 步】把本文件夹里的东西全部拷进去
  保持目录结构不变，拷完应该长这样：

    <游戏目录>\
      TransparentHer.exe            ← 游戏自带，不动
      winhttp.dll                   ← 本次新增
      doorstop_config.ini           ← 本次新增
      .doorstop_version             ← 本次新增
      nvdaControllerClient.dll      ← 本次新增
      changelog.txt                 ← 本次新增（BepInEx 自带说明）
      BepInEx\                      ← 本次新增，整个文件夹
        core\        （16 个文件，一个都不能少）
        plugins\
          TransparentHerA11y.dll        ← 模组本体
          nvdaControllerClient.dll      ← 冗余副本，放着无妨
          ZDSRAPI_x64.dll               ← 争渡读屏的 API，兜底，可删
          ZDSRAPI.dll                   ← 同上，32 位进程用的那一份

  三条容易踩的坑：
    · winhttp.dll、doorstop_config.ini、.doorstop_version 必须在
      **游戏根目录**，不能放进 BepInEx\ 里
    · BepInEx\core\ 里的 16 个文件一个都不能少
      （BepInEx.Preloader.dll 是 doorstop_config.ini 指定的入口）
    · nvdaControllerClient.dll 放游戏根目录 —— Mono 查找 DLL 时
      先看应用目录，放这儿最稳

  关于 plugins\ 里那两个 ZDSRAPI*.dll：那是**争渡读屏**的 API，
  随包只为**兜底**（给那些在自己机器上翻不到这个 dll 的人）。
  模组优先用你**争渡安装目录**里那份（它会跟着读屏一起升级）；
  包内这份旧了也会自动跳过、换下一份，不会卡住你。
  **删掉这两个文件即可**，模组回到「只读争渡安装目录」，功能不变。
  它们是争渡读屏的产物，我们未经修改地原样随这个免费非商业补丁再分发，
  依据是争渡官方 API 文档自己写的那句「应用程序……或者直接把 dll
  复制到指定的目录调用均可」；详见【技术说明】。

【第 3 步】启动
  · 试玩版：直接双击 TransparentHer.exe（不需要 Steam）
  · 正式版：从 Steam 正常启动（不要直接双击 exe）
  · 第一次启动会慢 10-30 秒，BepInEx 在生成 config 和缓存，正常

【第 4 步】确认装好了
  打开 <游戏目录>\BepInEx\LogOutput.log，应该能看到：

      Loading [TransparentHer A11y Reader 0.5.10.1]
      语音后端: NVDA
      Harmony 补丁已应用。
      TransparentHer A11y Reader 已加载。


========================================================
 如果之前装过别的 BepInEx 模组
========================================================

只需要两个文件：

    TransparentHerA11y.dll      → <游戏目录>\BepInEx\plugins\
    nvdaControllerClient.dll    → <游戏目录>\

**不要**覆盖对方已有的 winhttp.dll 和 BepInEx\core\，
版本冲突反而会让游戏打不开。只用 SAPI 的话 nvdaControllerClient.dll
可以不装。


========================================================
 卸载
========================================================

删掉游戏目录下这些（全部是本模组新增的）：

    winhttp.dll
    doorstop_config.ini
    .doorstop_version
    changelog.txt
    nvdaControllerClient.dll
    BepInEx\            （整个文件夹）

**只删 winhttp.dll 就足以让模组完全失效**，游戏立刻恢复原样。
存档在 %USERPROFILE%\AppData\LocalLow\Kawayi Play\TransparentHer\，
卸载不会碰到它。


========================================================
 朗读什么 / 不朗读什么
========================================================

[会朗读]
  · 无配音的剧情文本（旁白、主角「我」、少量无配音配角）
  · 手机（WeSay）聊天消息
  · 手机聊天里的表情/图片 → 提示为「图片」
  · 选项内容（剧情选项 + 手机选项）

[不会朗读]
  · 有配音的台词 —— 只播放语音，并打断上一句未读完的朗读，
    避免朗读和配音重叠
    （但这一句仍会被记下来：按 Backspace 可以让 TTS 把文字念一遍，
      语音错过了或者没听清时用得上）


========================================================
 按键
========================================================

  数字键 1 - 9      选择对应编号的选项（剧情选项、手机选项通用）
                    —— 必须用它，因为游戏原本的选项按钮是按屏幕
                       坐标散落摆放的，读屏无法定位
                    （已核对全部剧本：选项批次最多 4 个，1-9 够用）

  数字键 0          限时选择里「立刻沉默」（什么都不做，直接继续）
                    可在配置里改键或关闭

  Backspace         重读当前这一句
                    （有配音的台词也会被记下来，按它可以让 TTS 念一遍文字）

  F9                切换语音后端（自动 → Tolk → NVDA → 争渡 → SAPI → 自动）
                    每按一下切到下一个**当前可用**的后端，不可用的会被跳过
                    并在播报里说明（例如「语音后端：争渡读屏（已跳过 NVDA）」）。
                    选择会写进配置文件，下次启动仍生效。
                    可在配置项「切换语音后端按键」里改成 F9 / Alt+Shift+F9 /
                    Ctrl+Alt+F9 这类写法，留空则关闭。
                    注：中文 Windows 的输入法切换默认是 Alt+Shift，
                    如果你改成 Alt+Shift+F9 又觉得别扭，换成 Ctrl+Alt+F9。
                    修饰键必须完全匹配：配置写单键 F9 时，按住 Alt 再按 F9
                    不会触发（免得抢走别的键）。

  空格 / 回车       推进对话（游戏原有）
  Ctrl              快进（游戏原有，快进时不朗读）

【重要】以下按键游戏原生占用，模组不会去抢，也不要拿它们当重读键：
  A      自动模式
  F      快进
  P      打开主菜单
  R      打开历史回顾（Ending2 里是语音收藏）
  Esc    菜单 / 返回
  Ctrl   快进
  空格 / 回车 / 小键盘回车   推进

  重读键可以在配置里改成任意 KeyCode 名称，例如 Tab、Q、Home、F1。
  留空则关闭重读功能。


========================================================
 菜单 / 存档 / 设置 / 画廊的键盘导航
========================================================

游戏原本这些界面几乎只能鼠标点，现在可以纯键盘操作并朗读：

  Tab              进入 / 退出导航模式（进入时朗读「第几组，共 N 项」）
  上 / 下          上一项 / 下一项
  左 / 右          调整滑条（每按一次朗读新数值）
  回车 / 空格      激活 —— 按钮则点击，开关则切换，输入框则进入输入
  Home / End       跳到第一项 / 最后一项
  PageUp/PageDown  切换面板组

回车 / 空格的归属（只有这一条规则）：
  非导航模式                    → 不归模组，交给游戏推进剧情
  导航模式 + 当前没有可用控件    → 退出导航，交给游戏推进剧情
  导航模式 + 当前有可用控件      → 归模组，激活该控件

朗读内容示例：
    「通用，按钮，1 / 3」
    「画面模式，全屏模式，开关，开，3 / 14」
    「背景音乐，滑条，60%，6 / 14」
    「无存档，2026/09/11 07:30:35，空存档，2 / 5」

设置界面那些行名和页签名在游戏里是**美术字图片**，读屏拿不到，
模组按对象名做了中文映射，所以能读出「画面模式」「窗口分辨率」
「通用 / 音量 / 快捷键」这类名字。

激活控件后会在下一帧重新扫描界面（弹出的确认框、二级菜单会直接
接上，不用再按一次 Tab）。如果重新扫描后光标位置换了控件，会重新
播报「界面已更新。」加新控件 —— 不会让你按到没听过的东西。

★ 只导航最上层面板
  实测存档界面一次能扫到 13~20 个控件，其中只有 5 个是存档槽，
  其余是设置页签、画廊等无关按钮。现在按「Canvas 下的顶层面板」
  分组，默认只进入最上层那一组，避免在噪声里找目标。
  需要访问其它面板时按 PageUp / PageDown 切换。

★ 退出前二次确认
  标题画面有两个美术字按钮，文字分别是 START 和 EXIT，只差一个
  单词，而区分它们靠的是「哪一个是整块大面板、哪一个是角落小图标」
  —— 这种视觉信息读屏拿不到。所以在 EXIT 上按回车会先问一次，
  再按一次才真的退出。
  游戏**只在标题画面这一处**不给确认框；剧情中的「返回标题」、
  手机菜单的「退出游戏」游戏自己都会弹原生确认框，模组不会重复问。

========================================================
 配置
========================================================

首次启动游戏后生成：

    <游戏目录>\BepInEx\config\transparenther.a11y.reader.cfg

用记事本打开，改完保存，重启游戏生效。

  [朗读]
  朗读无配音剧情 = true
      关掉就完全不朗读剧情文本

  无法判定时也朗读 = true
      万一认不出当前这行有没有配音，选择朗读而不是跳过。
      建议保持 true，宁可多读也不要漏读。

  朗读时带上说话人 = true
      朗读时前面加上「诗梦：」「何璐：」这样的名字。旁白不加。

  朗读手机消息 = true
      手机（WeSay）聊天

  朗读手机表情 = true
      手机聊天里的表情/图片提示为「图片」

  语音后端 = 自动
      用哪个后端朗读。默认「自动」按 Tolk → NVDA → 争渡 → SAPI 的顺序挑第一个可用的。
      可填：自动 / Tolk / NVDA / 争渡 / SAPI（写 ZDSR 也认）。
      钉死某一个主要用来排查问题（例如填 SAPI 就能确认系统语音这条路通不通）；
      注意钉死之后**不会**自动降级，那个后端不可用就彻底没声了。
      平时不必改这一项：按「切换语音后端按键」就能现场换。

      争渡这一档**不需要你做任何事**：模组会先读 Windows「卸载」登记项里的
      InstallLocation（DisplayName 含「争渡」或 zdsr 的那些），自动找到争渡的
      安装目录；装在别的盘、装到自定义目录也算数。找不到再试默认位置。
      搜索顺序：注册表登记的安装目录 → 默认安装目录 → 插件目录（包内兜底那份）
      → 游戏目录。安装目录里那份**永远优先**。
      本安装包在 plugins\ 里带了 ZDSRAPI_x64.dll / ZDSRAPI.dll 两份兜底
      （32 / 64 位各一）；包内那份旧了会被自动跳过换下一份，
      **删掉它们即可回到「只读安装目录」**。见【技术说明】。
      争渡的 API 权限只随商业版 / 青春版提供；公益档下它一直回答
      「没运行或未授权」，模组会如实判不可用并继续往下试 SAPI。

  切换语音后端按键 = F9
      运行中切换语音后端的按键。可写修饰键组合，例如 F9、Alt+Shift+F9、
      Ctrl+Alt+F9；留空则关闭这个功能键。
      按一下切到下一个当前可用的后端（自动 → Tolk → NVDA → 争渡 → SAPI → 自动），
      当前不可用的会被跳过并在播报里说明；选择会写进本配置文件，下次启动仍生效。
      修饰键必须完全匹配：写 F9 时按住 Alt 再按 F9 不会触发。
      中文 Windows 的输入法切换默认占用了 Alt+Shift，需要组合键时
      建议用 Ctrl+Alt+F9。

  朗读选项 = true
      出现选项时朗读全部选项
  数字键选择选项 = true
      用 1-9 选择选项

  限时选择时长 = 20
      ★ 重要。游戏共 246 处「实时」限时选择，原本 8 秒到点会自动
      替你选 —— 也就是这一批的「沉默」分支（什么都不做）。
      读屏念完选项需要更多时间，所以默认放宽到 20 秒；
      沉默这个选项因此仍然存在，只是来得晚一些。
      填 8 即完全恢复游戏原版节奏。范围 1-600。
      注意：游戏自带的倒计时音效固定 8 秒，不会跟着变长；
      倒计时进度条会跟着这个值走。
      不想等就按「沉默按键」。

  沉默按键 = 0
      限时选择里立刻选「沉默」，不必等倒计时走完。
      填数字 0-9 时主键盘和小键盘都认；也可填 Z、F1 这类名称。
      留空则关闭。

  重读按键 = Backspace
      重读当前句的按键。填 KeyCode 名称，留空关闭。
      不要填 R / P / A / F / Ctrl / 空格 / 回车（游戏占用）。

  菜单键盘导航 = true
      上面那套 Tab 导航的开关。

  按屏幕位置排序控件 = true
      导航顺序按控件在屏幕上的位置排（先上后下、同一行先左后右），
      让「第几项」和画面对得上。
      关掉则改回按渲染层级（谁后画谁在前）排序。

  只导航看得见的控件 = true
      只把画面上真正能看到、能点到的控件纳入导航。
      游戏里有不少控件是「激活的」却停在画面外或被面板挡住，
      典型的是标题场景里整套手机菜单按钮 —— 手机面板本身在屏幕外，
      但按回车照样会触发。关掉它们就会重新出现在导航里。
      只有在发现正常按钮被误排除时才需要关掉。

  退出前二次确认 = true
      标题画面 EXIT 的二次确认开关。

  退出确认对象名 = ExitButton
      哪些控件需要那道二次确认，按 Unity 对象名精确匹配。
      多个名字用逗号分隔，留空关闭。

  [调试]

      排查完请关掉，否则日志会很大。


========================================================
 出问题了怎么办
========================================================

1) 完全没有声音
   · 打开 <游戏目录>\BepInEx\LogOutput.log，找这一行：
        语音后端: xxx
     - "Tolk (...)"  → 走 Tolk
     - "NVDA"        → 走 NVDA
     - "争渡读屏（ZDSR）" → 走争渡。这一行还会写出加载到的 DLL 路径与状态，
                       形如「…，DLL=…\ZDSRAPI_x64.dll，状态=空闲（可用）」。
                       若状态写的是「争渡没有运行，或当前是公益档/未授权
                       （GetSpeakState=2）」，就是争渡没开、或没有 API 权限
     - "SAPI"        → 没检测到读屏，用的系统语音
     - "无"          → 四个后端都不可用
   · 如果写着「没有可用的语音后端。逐个结论：…」，那一行会把每个后端
     各自的失败原因列出来（Tolk：…；NVDA：…；争渡：…；SAPI：…），照着看是哪一个的问题。
     注意到 SAPI 也在里面失败，说明系统语音本身有问题：
       - 看看系统「设置 → 时间和语言 → 语音」里有没有装中文语音
       - 在「讲述人」里试听一下，确认系统语音能出声
   · 若显示 SAPI 但你想要 NVDA：确认 NVDA 在游戏启动前就开着
   · 只装争渡、想要争渡出声：确认争渡正在运行，且是**商业版 / 青春版**
     （公益档没有 API 权限）；然后按 F9 切一下，或把配置「语音后端」填成「争渡」
     重启一次，看日志里争渡那一行自己的结论
   · 想确认某个后端单独能不能用：把配置「语音后端」填成 Tolk / NVDA / 争渡 / SAPI
     再启动一次，日志会直接给出这个后端自己的结论。
   · 现场换后端不必改配置：按 F9（可在「切换语音后端按键」里改）
     切到下一个当前可用的后端，不可用的会被跳过并在播报里说明

2) 游戏打不开 / 黑屏
   · 删掉 <游戏目录>\winhttp.dll，游戏立刻恢复原样
   · 或者打开 doorstop_config.ini，把 enabled = true 改成 false

3) 按空格推进剧情时顺手点到了界面按钮 —— 不应该发生。
   请把 LogOutput.log 发回来。

4) 限时选择卡住不动
   · 确认配置里「限时选择时长」不是被改成了很大的值
   · 按「沉默按键」（默认 0）可以直接继续

5) 朗读和配音同时响
   · 说明某行的配音识别失败了。把「无法判定时也朗读」关掉试试，
     但可能会漏读一些行。也欢迎反馈是哪一段。


========================================================
 技术说明（给愿意看的人）
========================================================

· 加载器：BepInEx 5.4.23.5（Unity Mono 版，winhttp.dll 代理注入）
· 朗读通道：Tolk / NVDA Controller Client / 争渡读屏（ZDSRAPI）/ SAPI，
  按可用性挑选。
  NVDA Controller Client 为官方 x64 构建，许可证 LGPL-2.1，
  允许随程序分发。
  争渡那一档加载 ZDSRAPI*.dll 的顺序是：
  注册表登记的安装目录 → 默认安装目录 → 插件目录（包内那份兜底）→ 游戏目录，
  顺序去重、安装目录那份永远优先（官方建议：那份会跟着读屏一起升级）。
  注册表路径用原始 advapi32 P/Invoke 读（不用 Microsoft.Win32.Registry），
  平台层因此保持零额外依赖，Mono / IL2CPP 两边都不用加包。
  包内那份若报版本不匹配（InitTTS 返回 1），模组会释放它、换下一份候选重来
  （最多 8 跳）；只有 1 会触发换候选，2 / 8 / 9 换多少份都一样。
  可用性判据是
  GetSpeakState() ∈ {3,4}（3=正在朗读、4=空闲），**不是** Speak() 的
  返回值 —— 未授权时 Speak() 照样返回 0。
· 第三方组件：本包除本模组外还带了 BepInEx、UnityDoorstop（winhttp.dll）、
  HarmonyX、Mono.Cecil、MonoMod，它们的许可证与来源说明都在
  licenses\ 目录里（BepInEx 5 等为 MIT，UnityDoorstop 与 NVDA Client
  为 LGPL-2.1）。**请不要删除 licenses\ 目录**，那是再分发的合规要求。
  另外 plugins\ 里的 ZDSRAPI_x64.dll / ZDSRAPI.dll 是**争渡读屏**的产物
  （不属于上列组件，也不受本模组的 MIT 许可覆盖）：未经修改、原样随这个
  免费非商业补丁再分发，依据是争渡官方 API 文档自己写的那句「应用程序……
  或者直接把 dll 复制到指定的目录调用均可」。我们与争渡官方没有隶属关系，
  也没有取得书面许可；**删掉这两个文件即可**（模组回到只读安装目录）。
  本包**不带 ZDSRAPI.ini** —— 那个是给玩家覆盖通道设置用的，随包带一份
  反而会覆盖玩家已经写好的选择。
· 工作方式：Harmony 运行时补丁（23 处），**不修改任何游戏文件**
· 不写注册表，不动系统目录，所有文件都在 <游戏目录> 内
· 判定是否有配音：用传入的最终文本反查 DialogueScene，
  读它的 VoiceFilename 字段是否为空
· 游戏版本：Unity 2022.3.43f1c1，Mono 后端

已实机验证（试玩版 + NVDA）：
  非导航模式空格只推进剧情不误触控件 / 限时选择沉默分支 /
  标题 EXIT 二次确认 / 设置界面朗读用途 / 界面变化后重新播报 /
  沉默按键

争渡这一档目前**只有开发机上的证据**（本作还没跑过）：
  · 平台层自检 71 条断言 0 失败（上一版 64 条；桩 DLL：DLL 不在 / 未授权 /
    可用 / 参数编组 / 掉线重连 / 不刷日志 / Stop / 点显器 / 按键解析。
    本版新增三条：注册表查找返回真实安装目录；某一份候选过期时被跳过、
    用了下一份；所有候选都过期时给出可读的「版本不匹配」原因）
  · 平台层编译检查 0 错误 0 警告
  · 真实平台代码 + 本机真实争渡：选中争渡连说 12 次，
    GetSpeakState() 12/12 = 3（正在朗读）；换 SAPI 说同一句，
    争渡保持 4（空闲）—— 正负对照
  · 四个仓库的发布包都重新组装过，两个 dll 都在 BepInEx\plugins\ 里
    （本包 37 个文件；ZDSRAPI_x64.dll 404,624 字节、ZDSRAPI.dll 328,336 字节）
  **没有验证**：
  · 玩家在游戏里听到的到底是不是争渡自己的声音（读屏自己也会出声，
    旁观者无法从音频上区分）
  · 本作自己的实机（默认键是单键 F9、本作占用键不受影响）都还没跑过 ——
    上表里的证据全在开发机上取得，**注册表自动查找**与**过期就换下一份**
    这两条新路径**没有在游戏里走过**
  · 点显器（盲文）输出**尚未接入**：接口在代码里，没接到朗读通路上
